# jjcat v0.9.4

메인 창과 별도 창의 모든 diff viewer가 layout과 whitespace 선택을 공유하고, 앱
재시작과 이후 in-app update restart 뒤에도 복원하는 macOS beta다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## v0.9.3에서 업데이트하기

1. 앱 메뉴의 **Check for Updates…**를 선택한다. 앱 시작 뒤 자동 확인에서 이미
   발견했다면 이 단계는 생략한다.
2. status bar 우측의 **Download jjcat 0.9.4**를 선택한다.
3. 다운로드와 signature 검증이 끝나 **Restart to update**가 나타날 때까지 기다린다.
4. 진행 중인 repository operation이 없는지 확인하고 **Restart to update**를 선택한다.

jjcat은 시작 약 1초 뒤 beta channel을 한 번 자동 확인한다. 열린 상태에서 주기적으로
polling하지 않으므로 이후 게시된 버전은 **Check for Updates…** 또는 앱 재시작으로
확인한다. update를 자동으로 내려받거나 강제로 재시작하지 않는다.

## 변경 사항

- `Unified / Side by side`와 `Whitespace — Show all / Ignore all` 선택을 모두
  app-owned local preference로 저장한다.
- change inspector, working copy와 그 밖의 메인 창 diff viewer가 동일한 선택을 공유한다.
- **Open in Window**로 연 별도 diff 창도 현재 선택을 이어받고, 그 창에서 변경한 값이
  메인 창에 즉시 반영된다.
- 마지막 선택을 quit/relaunch와 이후 in-app update restart 뒤에도 복원한다.

`v0.9.3`에서 저장한 unified/side-by-side 선택은 그대로 유지된다. whitespace는 첫
`v0.9.4` 실행에서 **Show all**로 시작하며, 이후 사용자가 변경한 선택부터 저장된다.

## 다운로드

수동 설치가 필요한 경우 다음 asset을 사용할 수 있다.

- `jjcat_0.9.4_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.4_aarch64.app.zip`: 압축된 앱 번들
- `jjcat_0.9.4_aarch64.app.tar.gz`: 서명된 updater archive
- `jjcat_0.9.4_aarch64.app.tar.gz.sig`: updater archive의 Tauri Minisign signature
- `latest-beta.json`: beta updater manifest
- `SHA256SUMS`: 모든 release asset의 다운로드 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 서명 및 Gatekeeper 경계

Updater archive는 Tauri Minisign signature를 필수로 검증한다. macOS app 자체는 번들
무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나 Apple에
notarization하지 않았다. 수동 설치 시 Gatekeeper가 차단하면 Finder의 **열기** 또는
**시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용한다. Gatekeeper를
끄거나 quarantine 속성을 제거할 필요는 없다.

## 알려진 제한

- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- 열린 앱은 update channel을 주기 polling하지 않는다.
- beta update는 자동 다운로드나 강제 재시작을 하지 않는다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

문제가 있으면 [GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를
남겨 달라.
