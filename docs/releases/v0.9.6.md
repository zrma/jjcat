# jjcat v0.9.6

장시간 실행 중인 jjcat으로 돌아왔을 때 새 beta update를 자동으로 다시 확인하는 macOS
beta다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## v0.9.5에서 업데이트하기

1. 앱 메뉴의 **Check for Updates…**를 선택한다. 앱 시작 뒤 자동 확인에서 이미
   발견했다면 이 단계는 생략한다. 포커스 기반 확인은 `v0.9.6`을 설치한 뒤의 다음
   update부터 동작한다.
2. status bar 우측의 **Download jjcat 0.9.6**을 선택한다.
3. 다운로드와 signature 검증이 끝나 **Restart to update**가 나타날 때까지 기다린다.
4. 진행 중인 repository operation이 없는지 확인하고 **Restart to update**를 선택한다.

jjcat은 시작 약 1초 뒤에도 기존처럼 beta channel을 확인한다. 자동 확인 결과 최신
버전이거나 일시적으로 실패한 경우에는 조용히 현재 작업을 유지한다. update를 자동으로
내려받거나 강제로 재시작하지 않는다.

## 변경 사항

- main window가 포커스를 얻고 3초간 유지되면 background update check를 예약한다.
- 3초 안에 다른 앱으로 전환하면 예약된 check를 취소한다.
- startup, focus-triggered와 manual 확인이 마지막 실제 시도 시각을 공유해 중복 요청을
  막는다.
- focus-triggered 확인은 1시간 cooldown을 적용한다. 메뉴의 수동 확인은 cooldown과
  무관하게 즉시 실행한다.
- fixed interval polling은 사용하지 않으므로 jjcat을 사용하지 않는 동안 불필요한
  network request를 만들지 않는다.

`v0.9.5`의 synchronized horizontal diff 탐색과 intraline 강조, 기존 diff
layout/whitespace 선택 및 창/inspector 배치는 그대로 유지된다.

## 다운로드

수동 설치가 필요한 경우 다음 asset을 사용할 수 있다.

- `jjcat_0.9.6_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.6_aarch64.app.zip`: 압축된 앱 번들
- `jjcat_0.9.6_aarch64.app.tar.gz`: 서명된 updater archive
- `jjcat_0.9.6_aarch64.app.tar.gz.sig`: updater archive의 Tauri Minisign signature
- `latest-beta.json`: beta updater manifest
- `SHA256SUMS`: 모든 release asset의 다운로드 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 서명 및 Gatekeeper 경계

Updater archive는 Tauri Minisign signature를 필수로 검증한다. macOS app 자체는 번들
무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나 Apple에
notarization하지 않았다. 수동 설치 시 Gatekeeper가 차단하면 Finder의 **열기** 또는
**시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용한다. Gatekeeper를
끄거나 quarantine 속성을 제거할 필요는 없다.

## 알려진 제한

- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- beta update는 자동 다운로드나 강제 재시작을 하지 않는다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

문제가 있으면 [GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를
남겨 달라.
