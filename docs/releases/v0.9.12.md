# jjcat v0.9.12

선택한 change에서 변경된 파일뿐 아니라 그 revision의 전체 tracked snapshot과 파일별
line provenance를 jjcat 안에서 탐색할 수 있게 한 macOS beta다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## v0.9.11에서 업데이트하기

1. 앱 시작 약 1초 뒤 또는 main window가 focus된 채 3초가 지나면 background update
   check가 실행된다. 바로 확인하려면 앱 메뉴의 **Check for Updates…**를 선택한다.
2. status bar 우측의 **Download jjcat 0.9.12**를 선택한다.
3. 다운로드와 signature 검증이 끝나 **Restart to update**가 나타날 때까지 기다린다.
4. 진행 중인 repository operation이 없는지 확인하고 **Restart to update**를 선택한다.
5. incoming `v0.9.12`가 기존 window 배치를 복원하고 macOS 전면으로 복귀한다.

자동 확인 결과 최신 버전이거나 일시적으로 실패한 경우에는 조용히 현재 작업을 유지한다.
update를 자동으로 내려받거나 강제로 재시작하지 않는다.

## 변경 사항

- Changes inspector에 **File Tree** tab을 추가해 선택 revision의 전체 tracked tree와 file
  type, conflict, executable 및 selected-change status를 표시한다.
- snapshot file을 선택하면 exact path membership을 다시 확인하고 bounded source content를
  lazy loading한다. binary와 truncated state를 명시하며 source는 registry/cache에 저장하지
  않는다.
- Working Copy, Changes와 File Tree context menu에 **Blame / Timeline…** action을 추가한다.
- 별도 app-owned window에서 path-filtered change history, grouped line provenance, revision
  selector와 older/newer timeline navigation을 제공한다.
- 과거 revision을 읽은 뒤에도 이미 본 newer history를 window session에 유지해 시작
  revision으로 돌아갈 수 있다.
- local과 SSH가 같은 structured query, exact fileset, bounded output와 redacted error
  contract를 사용한다.
- File Tree는 Arrow Up/Down, Home/End, context-menu key와 `Shift+F10`을 지원하고 Timeline은
  Arrow Left/Right와 Escape를 지원한다.
- `v0.9.11`의 file context actions, foreground activation, window/splitter 복원, diff viewer
  preference와 update-check cadence는 그대로 유지한다.

## 다운로드

수동 설치가 필요한 경우 다음 asset을 사용할 수 있다.

- `jjcat_0.9.12_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.12_aarch64.app.zip`: 압축된 앱 번들
- `jjcat_0.9.12_aarch64.app.tar.gz`: 서명된 updater archive
- `jjcat_0.9.12_aarch64.app.tar.gz.sig`: updater archive의 Tauri Minisign signature
- `latest-beta.json`: beta updater manifest
- `SHA256SUMS`: 모든 release asset의 다운로드 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 서명 및 Gatekeeper 경계

Updater archive는 Tauri Minisign signature를 필수로 검증한다. macOS app 자체는 번들
무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나 Apple에
notarization하지 않았다. 수동 설치 시 Gatekeeper가 차단하면 Finder의 **열기** 또는
**시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용한다. Gatekeeper를
끄거나 quarantine 속성을 제거할 필요는 없다.

## 알려진 제한

- rename/copy 이전 path를 추적하는 cross-path history는 제공하지 않는다.
- file edit/save 또는 arbitrary revision restore는 제공하지 않는다.
- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- beta update는 자동 다운로드나 강제 재시작을 하지 않는다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

문제가 있으면 [GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를
남겨 달라.
