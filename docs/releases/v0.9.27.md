# jjcat v0.9.27

Tauri 업데이터 `2.14.1`을 적용한 Apple Silicon macOS 베타다. macOS 13 이상과 Jujutsu `0.43.x`를 지원한다.
같은 소스의 Windows 대상 업데이터는 보안 수정이 적용된 `zip 9.0.5`를 사용한다. [의존성 업데이트](https://github.com/zrma/jjcat/pull/3)

## v0.9.26에서 업데이트하기

1. 앱 메뉴에서 **Check for Updates…**를 선택한다.
2. 상태 표시줄에서 **Download jjcat 0.9.27**을 선택한다.
3. 다운로드와 서명 검증이 끝나면, 진행 중인 저장소 작업을 마친 뒤 **Restart to update**를 선택한다.

## 다운로드

- `jjcat_0.9.27_aarch64.dmg`
- `jjcat_0.9.27_aarch64.app.zip`
- `jjcat_0.9.27_aarch64.app.tar.gz`
- `jjcat_0.9.27_aarch64.app.tar.gz.sig`
- `latest-beta.json`
- `SHA256SUMS`

`shasum -a 256 -c SHA256SUMS`로 다운로드를 검증할 수 있다. 앱 번들은 ad-hoc 서명을 사용하며, 앱 내 업데이터는 Tauri Minisign 서명으로 업데이트를 검증한다. 배포 방식의 세부 사항은 [공개 배포 정책](../PUBLICATION.md)을 참고한다.
