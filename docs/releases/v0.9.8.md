# jjcat v0.9.8

진행 중인 작업과 실제 오류의 의미를 분리하고, 기다림이 필요한 주요 작업에 일관된
activity feedback을 제공하는 macOS beta다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## v0.9.7에서 업데이트하기

1. 앱 시작 약 1초 뒤 또는 main window가 focus된 채 3초가 지나면 background update
   check가 실행된다. 바로 확인하려면 앱 메뉴의 **Check for Updates…**를 선택한다.
2. status bar 우측의 **Download jjcat 0.9.8**을 선택한다.
3. 다운로드와 signature 검증이 끝나 **Restart to update**가 나타날 때까지 기다린다.
4. 진행 중인 repository operation이 없는지 확인하고 **Restart to update**를 선택한다.

자동 확인 결과 최신 버전이거나 일시적으로 실패한 경우에는 조용히 현재 작업을 유지한다.
update를 자동으로 내려받거나 강제로 재시작하지 않는다.

## 변경 사항

- active repository mutation과 겹친 refresh를 failure 대신 `Waiting to refresh`로 표시한다.
- repository notice와 Command Activity가 같은 waiting 의미와 중립적인 activity 색상을 쓴다.
- 초기 repository load, diff/operation load, source scan, remote folder 탐색, repository
  추가, mutation preview/execute와 Undo/Redo에 공통 CLI형 spinner를 적용했다.
- 실제 SSH/driver 실패와 recovery warning은 경고 아이콘, cache와 retry 정보를 유지한다.
- Quick Look 오류가 repository refresh health를 failed/disconnected로 바꾸지 않게 분리했다.
- 좁은 창에서도 실행 중인 Undo/Redo indicator가 유지되며 reduced-motion 환경에서는
  움직이지 않는 activity glyph를 사용한다.

실제 percentage를 알 수 없는 작업에 가짜 진행률을 추가하지 않았다. `v0.9.7`의 고정된
repository navigation과 source scroll 위치 보존, 기존 diff 가독성, layout/whitespace
선택과 창/inspector 배치는 그대로 유지된다.

## 다운로드

수동 설치가 필요한 경우 다음 asset을 사용할 수 있다.

- `jjcat_0.9.8_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.8_aarch64.app.zip`: 압축된 앱 번들
- `jjcat_0.9.8_aarch64.app.tar.gz`: 서명된 updater archive
- `jjcat_0.9.8_aarch64.app.tar.gz.sig`: updater archive의 Tauri Minisign signature
- `latest-beta.json`: beta updater manifest
- `SHA256SUMS`: 모든 release asset의 다운로드 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 서명 및 Gatekeeper 경계

Updater archive는 Tauri Minisign signature를 필수로 검증한다. macOS app 자체는 번들
무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나 Apple에
notarization하지 않았다. 수동 설치 시 Gatekeeper가 차단하면 Finder의 **열기** 또는
**시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용한다. Gatekeeper를
끄거나 quarantine 속성을 제거할 필요는 없다.

## 알려진 제한

- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- beta update는 자동 다운로드나 강제 재시작을 하지 않는다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

문제가 있으면 [GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를
남겨 달라.
