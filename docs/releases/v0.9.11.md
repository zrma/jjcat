# jjcat v0.9.11

Working Copy와 Changes inspector의 파일에서 바로 자주 쓰는 작업을 실행할 수 있는 compact
context menu를 추가한 macOS beta다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## v0.9.10에서 업데이트하기

1. 앱 시작 약 1초 뒤 또는 main window가 focus된 채 3초가 지나면 background update
   check가 실행된다. 바로 확인하려면 앱 메뉴의 **Check for Updates…**를 선택한다.
2. status bar 우측의 **Download jjcat 0.9.11**을 선택한다.
3. 다운로드와 signature 검증이 끝나 **Restart to update**가 나타날 때까지 기다린다.
4. 진행 중인 repository operation이 없는지 확인하고 **Restart to update**를 선택한다.
5. incoming `v0.9.11`이 기존 window 배치를 복원하고 macOS 전면으로 복귀한다.

자동 확인 결과 최신 버전이거나 일시적으로 실패한 경우에는 조용히 현재 작업을 유지한다.
update를 자동으로 내려받거나 강제로 재시작하지 않는다.

## 변경 사항

- Working Copy와 Changes inspector의 file tree에서 우클릭하면 선택한 파일 가까이에 compact
  context menu가 나타난다.
- **Open Diff**, **Open in VS Code**, **Show in Finder**, **Split This File…**와
  **Copy Path**를 제공한다.
- context menu key와 `Shift+F10`으로 pointer와 같은 menu를 열 수 있다.
- split은 선택한 exact file path 하나만 기존 preview-first mutation flow로 전달한다.
- local/SSH VS Code handoff와 local Finder reveal은 validated repository-relative path를
  shell을 거치지 않는 structured argument로 전달한다.
- SSH repository에서는 지원하지 않는 Finder action을 disabled state로 표시한다.
- `v0.9.10`의 bootstrap-safe foreground activation, window/splitter 복원, diff viewer
  preference와 update-check cadence는 그대로 유지한다.

## 다운로드

수동 설치가 필요한 경우 다음 asset을 사용할 수 있다.

- `jjcat_0.9.11_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.11_aarch64.app.zip`: 압축된 앱 번들
- `jjcat_0.9.11_aarch64.app.tar.gz`: 서명된 updater archive
- `jjcat_0.9.11_aarch64.app.tar.gz.sig`: updater archive의 Tauri Minisign signature
- `latest-beta.json`: beta updater manifest
- `SHA256SUMS`: 모든 release asset의 다운로드 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 서명 및 Gatekeeper 경계

Updater archive는 Tauri Minisign signature를 필수로 검증한다. macOS app 자체는 번들
무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나 Apple에
notarization하지 않았다. 수동 설치 시 Gatekeeper가 차단하면 Finder의 **열기** 또는
**시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용한다. Gatekeeper를
끄거나 quarantine 속성을 제거할 필요는 없다.

## 알려진 제한

- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- beta update는 자동 다운로드나 강제 재시작을 하지 않는다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

문제가 있으면 [GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를
남겨 달라.
