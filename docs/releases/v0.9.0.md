# jjcat v0.9.0

jjcat의 첫 macOS public beta다. 여러 로컬 및 OpenSSH 원격 Jujutsu 저장소를
한 창에서 탐색하고, change·workspace·bookmark·operation을 GUI로 관리할 수 있다.

## 지원 범위

- Apple Silicon Mac (`arm64`)
- macOS 13 이상
- Jujutsu `0.43.x`
- 로컬 저장소와 OpenSSH host alias 기반 원격 저장소

## 다운로드

- `jjcat_0.9.0_aarch64.dmg`: 일반 설치용 디스크 이미지
- `jjcat_0.9.0_aarch64.app.zip`: 압축된 앱 번들
- `SHA256SUMS`: 다운로드 검증용 체크섬

같은 디렉터리에서 다음 명령으로 다운로드를 검증할 수 있다.

```sh
shasum -a 256 -c SHA256SUMS
```

## 처음 실행하기

이 beta는 번들 무결성을 위해 ad-hoc 서명했지만 Apple Developer ID로 서명하거나
Apple에 notarization하지 않았다. 따라서 macOS Gatekeeper가 첫 실행을 차단할 수
있다.

1. DMG를 열고 `jjcat.app`을 Applications 폴더로 복사한다.
2. Finder에서 `jjcat.app`을 Control-클릭한 뒤 **열기**를 선택한다.
3. 이 경로로 열 수 없다면 **시스템 설정 → 개인정보 보호 및 보안**에서 차단된
   jjcat 항목의 **확인 없이 열기**를 선택한다.
4. 표시된 앱 이름과 출처를 확인한 뒤 실행을 승인한다.

Gatekeeper를 끄거나 quarantine 속성을 제거할 필요는 없다. Apple의 공식 설명은
[확인되지 않은 개발자의 앱 열기](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)와
[macOS의 Gatekeeper 및 런타임 보호](https://support.apple.com/en-us/102445)를 참고한다.

## 알려진 제한

- Intel Mac용 빌드는 제공하지 않는다.
- Developer ID 서명과 notarization을 제공하지 않는다.
- 자동 업데이트 기능은 없다.
- 원격 저장소는 비대화형 OpenSSH 접속과 원격 `jj` 설치가 필요하다.

중요한 저장소 변경은 preview와 exact target을 확인한 뒤 실행하고, 문제가 있으면
[GitHub Issues](https://github.com/zrma/jjcat/issues)에 재현 절차를 남겨 달라.
